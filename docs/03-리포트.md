# 리포트 — 담당: 강영주
(11/2 차장님 답변: 직원 "내 평가 결과" 없음, 등급 없음, 공개 범위 대신 "결과 확정". 개인 리포트·종합 의견은 관리자만)
(11/3: 리포트는 개인 리포트(면담 리포트 통합, 대시보드형) / 전체 리포트(요약) 둘로 나눈다)
기한: 11/1 화면(가짜 데이터) → 11/4 실제 데이터 연결

## 0. 목표
발표 6번 장면: 관리자가 "결과 확정"을 누르면 확정 결과가 저장되고 잠긴다 → 관리자가 개인 리포트를 본다.
확정하는 쪽(결과 확정)과 보는 쪽(개인 리포트·전체 리포트)을 한 사람이 맡아 서로 맞춘다.

## 1. 페이지·폴더
| 주소 | 폴더 | 이번 범위 |
|---|---|---|
| /admin/reports | reports | ✅ 리포트 첫 화면 (개인 리포트 / 전체 리포트 카드 2개) |
| /admin/reports/personal | reports | ✅ 결과 확정 + 개인 리포트(관리자 전용) + 인쇄 |

## 2. 화면 구성

### 리포트 (/admin/reports → 개인 리포트 /personal · 전체 리포트 /all)
1. 결과 확정 상태: "확정 전" 또는 "확정됨 · 11/4 14:00" (첫 화면 개인 리포트 카드에도 표시)
2. 개인 리포트(대시보드형): 최종 점수·개인 평가(임원은 임원상향평가)·비율 반영·보정 / 단계별 점수 / 부서 KPI(점수·반영 비율·계산식) / 본인이 한 상향 평가 / 종합 의견 (관리자만)
3. 직원 한 명 고르기 → 그 직원의 개인 리포트 (확정 전엔 현재 점수, 확정 후엔 확정 결과)
4. [결과 확정] 버튼 → 확인 창 "지금 점수로 확정 결과를 저장합니다. 확정하면 비율·KPI·보정을 바꿀 수 없습니다." (취소는 [확정 취소])
5. [확정 취소] 버튼 (확정된 상태에서만) → 확인 창 "잠금을 풉니다. 확정 결과는 지우지 않고 남겨 둡니다."
6. 전체 리포트: [전체 결과 엑셀로 내려받기] 버튼 (관리자 전용, 점수·평가 의견·건의사항(익명), 확정 전이면 현재 점수)
7. 면담 리포트는 개인 리포트에 통합

### 개인 리포트 인쇄 (11/4 추가, 리포트 > 개인 리포트)
- [인쇄] (미리보기 옆): 고른 1명만 인쇄
- 여러 명 인쇄: 범위(전체 / 결과에 있는 부서) 고르기 → [○○ 개인 리포트 인쇄 (N명)]. 한 사람씩 새 쪽에서 시작
- 브라우저 인쇄 창을 연다. 인쇄 창에서 "PDF로 저장"을 고르면 파일이 된다 (PDF를 코드로 만들지 않음)
- PDF 파일 이름(인쇄 직전 문서 제목): 개인리포트_이름_평가이름 / 개인리포트_부서_평가이름 / 개인리포트_전체_평가이름. 인쇄가 끝나면 제목을 되돌린다
- 인쇄 모양: A4 세로, 여백 15mm. 맨 위 머리말(평가 이름 · 이름 · 부서 · 직급 · 출력 날짜). 사이드바·상단바·버튼·선택 상자는 나오지 않는다
- 점수는 화면과 같은 값 (scoring.ts 계산을 그대로 읽는다). 확정 전이면 현재 점수, 확정 후면 확정 결과
- "본인이 한 상향 평가"는 인쇄물에 넣지 않는다 (인쇄물이 돌아다녀도 상향 평가의 익명이 지켜지게). 화면에는 그대로 있다
- 직원용 [PDF로 저장](내 평가 결과)과는 다른 기능이다. 내 평가 결과는 쓰지 않는다

### 내 평가 결과 (/my/results)
- 쓰지 않는다 (11/2 차장님 답변). 메뉴에서 숨기고, 직원이 주소로 들어오면 첫 페이지로 보낸다

## 3. 동작
- 리포트는 상단바 평가 선택 상자에서 고른 평가의 결과를 보여 준다
- [결과 확정] → 그 순간 다시 읽어 scoring.ts로 계산한 결과를 확정 결과 표에 저장하고, 평가 설정의 결과 확정(result_published)을 켠다. 평가 상태는 평가 중 → 완료 (016)
- 확정 후 개인 리포트·인쇄·엑셀은 확정 결과만 본다
- 확정 후 잠긴다. 바꾸려면 [확정 취소] → 수정 → 다시 확정
- [확정 취소] → 확정 결과는 지우지 않고 남겨 두고 잠금만 푼다. 평가 상태는 완료 → 평가 중
- 엑셀은 CSV 파일로 만든다 (새 라이브러리 없이). 엑셀에서 한글이 깨지지 않도록 파일 맨 앞에 BOM을 붙인다

## 5. 볼 수 있는 사람
- /admin/reports: 관리자만

## 6. 하지 않을 것
- 평가 의견 한 건씩 검토·공개 (결과를 직원에게 공개하지 않음)
- 직원 개인 엑셀
- PDF를 코드로 직접 만들기 (브라우저 인쇄만)
- 메일·카톡 발송

## 7. 완료 체크리스트

### 리포트 (관리자)
- [ ] 직원을 고르면 개인 리포트가 바로 바뀐다
- [ ] [결과 확정] 누르면 확인 창이 뜨고, 확정 후 "확정됨 · 시각"과 잠금 안내가 보인다
- [ ] 확정 후 점수·보정 페이지도 "수정 불가"가 된다 (오재란 페이지와 함께 확인)
- [ ] [확정 취소] 하면 잠금이 풀리고, 확정 결과는 남는다
- [ ] [전체 결과 엑셀로 내려받기] → 엑셀에서 열었을 때 한글이 안 깨진다

### 개인 리포트 인쇄 (관리자)
- [ ] [인쇄] → 인쇄 미리보기에 고른 1명만, A4 한 쪽에 나온다
- [ ] 범위 "전체" → 모든 사람이 한 사람씩 새 쪽에서 시작한다
- [ ] 범위에서 부서를 고르면 그 부서 사람만 나온다 (버튼에 인원수가 맞게 보인다)
- [ ] 사이드바·상단바·버튼·선택 상자가 인쇄되지 않는다
- [ ] 카드·의견이 쪽 경계에서 잘리지 않는다
- [ ] "PDF로 저장" 파일 이름이 개인리포트_이름(부서·전체)_평가이름 이다
- [ ] 인쇄 창을 닫으면 화면과 탭 제목이 원래대로 돌아온다
- [ ] "배경 그래픽" 설정을 꺼도 단계별 점수 막대가 보인다
- [ ] 인쇄물에 "본인이 한 상향 평가"가 없다
