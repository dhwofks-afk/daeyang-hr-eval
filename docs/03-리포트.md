# 리포트 — 담당: 강영주
(11/2 차장님 답변: 직원 "내 평가 결과" 없음, 등급 없음, 공개 범위 대신 "결과 확정". 개인 리포트·종합 의견은 관리자만)
(11/3: 리포트는 개인 리포트(면담 리포트 통합, 대시보드형) / 전체 리포트(요약) 둘로 나눈다)
기한: 11/1 화면(가짜 데이터) → 11/4 실제 데이터 연결

## 0. 목표
발표 6번 장면: 관리자가 "결과 확정"을 누르면 확정 결과가 저장되고 잠긴다 → 관리자가 개인 리포트를 본다.
공개하는 쪽(관리자)과 보는 쪽(직원)을 한 사람이 맡아 서로 맞춘다.

## 1. 페이지·폴더
| 주소 | 폴더 | 이번 범위 |
|---|---|---|
| /admin/reports | reports | ✅ 결과 확정 + 개인 리포트(관리자 전용) + 전체 결과 엑셀 |
| /my/results | my-results | ❌ 쓰지 않음 (메뉴에서 숨김, 주소로 들어오면 첫 페이지로) |

## 2. 화면 구성

### 리포트 (/admin/reports)
1. 공개 상태: "미공개" 또는 "공개됨 · 11/4 14:00"
2. 개인 리포트(대시보드형): 단계별 점수 / 최종 점수 / 본인이 한 상향 평가 / 부서 KPI / 종합 의견 (관리자만)
3. 개인 리포트 미리보기: 직원 한 명 고르기 → "이 직원에게 이렇게 보입니다" 화면
4. [결과 확정] 버튼 → 확인 창 "확정하면 비율·KPI·보정을 바꿀 수 없습니다" (취소는 [확정 취소])
5. [공개 취소] 버튼 (공개된 상태에서만) → 경고 "직원 화면에서 결과가 다시 숨겨집니다"
6. [전체 결과 엑셀로 내려받기] 버튼 (관리자 전용, 공개 여부와 상관없이 전 항목)
7. 전체 리포트(요약): 전 직원 결과 요약 (면담 리포트는 개인 리포트에 통합)

### 개인 리포트 인쇄 (11/4 추가, 리포트 > 개인 리포트)
- [인쇄] (미리보기 옆): 고른 1명만 인쇄
- 여러 명 인쇄: 범위(전체 / 결과에 있는 부서) 고르기 → [○○ 개인 리포트 인쇄 (N명)]. 한 사람씩 새 쪽에서 시작
- 브라우저 인쇄 창을 연다. 인쇄 창에서 "PDF로 저장"을 고르면 파일이 된다 (PDF를 코드로 만들지 않음)
- PDF 파일 이름(인쇄 직전 문서 제목): 개인리포트_이름_평가이름 / 개인리포트_부서_평가이름 / 개인리포트_전체_평가이름. 인쇄가 끝나면 제목을 되돌린다
- 인쇄 모양: A4 세로, 여백 15mm. 맨 위 머리말(평가 이름 · 이름 · 부서 · 직급 · 출력 날짜). 사이드바·상단바·버튼·선택 상자는 나오지 않는다
- 점수는 화면과 같은 값 (scoring.ts 계산을 그대로 읽는다). 확정 전이면 현재 점수, 확정 후면 확정 결과
- "본인이 한 상향 평가"는 인쇄물에 넣지 않는다 (인쇄물이 돌아다녀도 상향 평가의 익명이 지켜지게). 화면에는 그대로 있다
- 직원 화면의 [PDF로 저장](아래 "내 평가 결과")과는 다른 기능이다. 내 평가 결과는 쓰지 않으므로 이번에 만들지 않았다

### 내 평가 결과 (/my/results)
- 공개 전: "결과 준비 중" 안내만
- 공개 후: 공개 범위에 체크된 항목만, 확정 결과 기준으로 보여 줌
- 점수·등급은 숫자·글자로 크게 (고령 직원 고려)
- [PDF로 저장] 버튼: 브라우저 인쇄 창을 연다. 인쇄용 모양에서는 사이드바·버튼을 숨기고 결과만 나오게 한다

## 3. 동작
- [결과 확정] → 그 순간 scoring.ts로 계산한 결과를 확정 결과 표에 저장하고, 평가 설정의 결과 확정(result_published)을 켠다
- 공개 후 직원 화면은 확정 결과만 본다 (관리자가 뭘 바꿔도 직원 화면은 그대로)
- 확정 후 잠긴다. 바꾸려면 [확정 취소] → 수정 → 다시 확정
- [공개 취소] → 확정 결과는 지우지 않고 남겨 두되, 직원 화면은 다시 "준비 중"
- 엑셀은 CSV 파일로 만든다 (새 라이브러리 없이). 엑셀에서 한글이 깨지지 않도록 파일 맨 앞에 BOM을 붙인다

## 5. 볼 수 있는 사람
- /admin/reports: 관리자만
- /my/results: 로그인한 본인 결과만. 다른 사람 결과는 어떤 방법으로도 볼 수 없어야 한다

## 6. 하지 않을 것
- 평가 의견 한 건씩 검토 (체크리스트로 일괄 공개/비공개만)
- 직원 개인 엑셀
- PDF를 코드로 직접 만들기 (브라우저 인쇄만)
- 메일·카톡 발송

## 7. 완료 체크리스트

### 리포트 (관리자)
- [ ] 공개 범위를 바꾸면 미리보기 화면이 바로 바뀐다
- [ ] [결과 공개] 누르면 확인 창이 뜨고, 공개 후 체크리스트가 잠긴다
- [ ] 공개 후 점수·보정 페이지도 "수정 불가"가 된다 (오재란 페이지와 함께 확인)
- [ ] [공개 취소] 하면 직원 화면이 다시 "준비 중"이 된다
- [ ] [전체 결과 엑셀로 내려받기] → 엑셀에서 열었을 때 한글이 안 깨진다

### 개인 리포트 인쇄 (관리자)
- [ ] [인쇄] → 인쇄 미리보기에 고른 1명만, A4 한 쪽에 나온다
- [ ] 범위 "전체" → 모든 사람이 한 사람씩 새 쪽에서 시작한다
- [ ] 범위에서 부서를 고르면 그 부서 사람만 나온다 (버튼에 인원수가 맞게 보인다)
- [ ] 사이드바·상단바·버튼·선택 상자가 인쇄되지 않는다
- [ ] 카드·의견이 쪽 경계에서 잘리지 않는다
- [ ] "PDF로 저장" 파일 이름이 개인리포트_이름(부서·전체)_평가이름 이다
- [ ] 인쇄 창을 닫으면 화면과 탭 제목이 원래대로 돌아온다
- [ ] "배경 그래픽" 설정을 꺼도 단계별 점수 막대가 보인다
- [ ] 인쇄물에 "본인이 한 상향 평가"가 없다

### 내 평가 결과 (직원)
- [ ] 공개 전엔 "결과 준비 중"만 보인다
- [ ] 공개 후엔 체크된 항목만 보인다
- [ ] 공개 후 관리자가 KPI를 바꿔도 직원 화면 점수는 그대로다
- [ ] 팀원에겐 상향 평가 항목이 안 보이고, 팀장에겐 체크된 경우만 보인다
- [ ] [PDF로 저장] → PDF에 화면에 보이는 항목만 들어간다
- [ ] 휴대폰 너비에서 글씨가 크게 잘 보인다
- [ ] pnpm build, pnpm exec tsc --noEmit 통과
