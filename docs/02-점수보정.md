## 0. 목표
발표 5번 장면: 제출된 평가가 가중 합산되고 → 부서 KPI가 반영되고 → 필요하면 최종 점수를 보정하고 → 부서별 등급이 자동으로 나온다.
특히 "KPI나 보정을 바꾸면 점수와 등급이 바로 바뀌는 장면"을 보여 준다. (부서 성과 연동형 = 프로젝트 핵심)

점수 순서: 가중 합산 → KPI 반영 → 최종 점수 보정(선택) → 등급 자동 산출

## 2. 화면 구성

### 평가 결과 (/admin/scores/results)
1. 위쪽 요약: 회차 이름, 상태, 제출 현황(제출 n / 전체 n), 현재 가중치(읽기 전용)
2. 부서 선택: 전체 / 경영기획부 / 영업부 / 생산
3. 결과 표 (부서 → 순위 순)
   이름 · 직급 · 역할 · 자기 · 팀장 · 임원 · 상향 · 가중 합산 · KPI 반영 · 최종 · 등급
   - 미제출 단계는 "미제출(0)"로 빨간 표시
   - KPI 반영 점수 옆에 가중 합산 대비 +/− 표시 (예: 80.4 → 80.8 ▲0.4)
   - 보정된 사람은 최종 점수에 표시

### KPI 반영 (/admin/scores/kpi)
1. 반영 방식: 가산 / 배율 (하나 선택)
2. 기준값, 계수 입력
3. 계산 미리보기: "개인 80점, 부서 KPI 90점이면 → OO점" (입력값이 바뀌면 바로 바뀜)
4. 부서별 KPI 입력 표: 부서명 · 인원 · KPI 점수(입력) · 반영 전 평균 · 반영 후 평균
5. [저장] 버튼

### 최종 점수 보정 (/admin/scores/adjust)
1. 부서 선택
2. 보정 표 (부서 → 순위 순)
   이름 · KPI 반영 점수 · 보정 점수(입력, 비우면 보정 없음) · 사유(선택) · 최종 점수 · 등급
   - 한 화면에서 보정 전·후를 나란히 비교
   - 보정한 줄은 색으로 표시
3. 등급 비율: A / B / C / D (합계 100인지 검사)
4. [저장] 버튼
5. 보정 기록: 누가 · 언제 · 누구를 · 몇 점 → 몇 점 · 사유

## 3. 동작
- KPI [저장] → 평가 설정·부서 표에 저장되고, 평가 결과 표가 새 값으로 다시 계산된다.
- 보정 [저장] → 최종 점수가 바뀌고 그 부서 등급이 다시 계산된다. 보정 기록에 한 줄 쌓인다 (지우거나 고칠 수 없음).
- 점수·등급은 저장하지 않고 scoring.ts로 그때그때 계산한다.
- "결과 공개" 후에는 KPI·보정·등급 비율을 바꿀 수 없다. 화면에 "결과 공개됨 · 수정 불가" 표시.

### 11/1까지 (가짜 데이터)
- src/data/scores.ts 새 파일에 위 표와 같은 칸 이름으로 가짜 데이터를 만든다.
- 직원 27명은 src/data/people.ts를 그대로 쓴다 (읽기만).
- 평가 건·답까지 가짜로 만들긴 너무 크므로, 직원별 단계 점수(자기·팀장·임원·상향)를 바로 넣어 시작한다.
- 가짜 단계 점수는 회사 평가표의 배점 구조에 맞춰 분야별로 만든다.
  - 팀원: 업무성과 35 / 능력 20 / 근무태도 20 / 보안·규정 10 / 조직문화 15
  - 팀장: 업무성과 35 / 능력 20 / 리더십 45
- 실제 문항 데이터는 05-서버기반에서 공통 파일로 만든다 (평가표 5종 그대로).
- scoring.ts는 두 층으로 나눈다.
  - 아래층: 답 → 단계 점수 (11/4 실제 연결 때 사용)
  - 위층: 단계 점수 → 가중 합산 → KPI 반영 → 보정 → 등급 (11/1부터 가짜 데이터로 사용)

## 5. 볼 수 있는 사람
- 관리자만. 다른 역할이 주소로 들어오면 자기 첫 페이지로 돌아간다 (골격에 이미 있음).

## 6. 하지 않을 것
- 등급을 직접 고치는 기능 (등급은 항상 최종 점수로 자동 계산)
- 가중치 수정 화면 (기본값 사용)
- 결과 공개 버튼 (리포트 담당)
- 엑셀 내려받기 (전체 결과 엑셀은 리포트 페이지에서)
- 상향 평가 입력 (점수 표시만)

## 7. 완료 체크리스트

### 계산 (scoring.ts)
- [ ] 개인 80, 부서 KPI 90, 기준 80, 계수 0.2 → 가산 82
- [ ] 기준 미달 부서는 점수가 내려간다
- [ ] 결과가 0 아래, 100 위로 나가지 않는다
- [ ] 등급 인원: 3명 A1 B1 C1 D0 / 6명 A2 B1 C2 D1 / 18명 A5 B4 C6 D3
- [ ] 동점자는 같은 등급(높은 쪽)
- [ ] 보정 점수가 있으면 그 값으로 등급을 매긴다

### 화면
- [ ] KPI 값을 바꾸고 저장하면 평가 결과 표의 점수·등급이 바뀐다
- [ ] 가산·배율 둘 다 미리보기 숫자가 맞다
- [ ] 보정하면 최종 점수와 그 부서 등급이 다시 계산되고, 보정 기록에 한 줄 생긴다
- [ ] 등급 비율 합이 100이 아니면 저장되지 않는다
- [ ] 가짜 데이터에서 "결과 공개"를 켜면 KPI·보정·등급 비율이 잠긴다
- [ ] 점수는 모두 숫자로 표시된다
