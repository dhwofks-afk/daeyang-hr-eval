# 16. 사용 설명서 (관리자용, 초안)
(11/3 초안. 실제 연결이 끝나면 화면 문구에 맞춰 다시 고친다)

인사평가 웹앱을 관리자가 1년 동안 운영하는 순서입니다.
위에서 아래로 차례대로 하면 됩니다.

## 0. 시작하기
- 주소: https://daeyang-hr-eval.onrender.com
- 관리자는 로그인 화면의 [관리자 로그인]에서 아이디·비밀번호로 들어갑니다.
- 직원은 이름과 사번으로 로그인합니다. 직원 화면에는 자기 평가 목록만 보입니다.
- 왼쪽 메뉴(휴대폰은 위쪽 메뉴 단추): 대시보드 / 사람·조직 / 평가 설계 / 진행 관리 / 점수·보정 / 리포트 / 건의함 / 데이터 관리

### 한눈에 보는 순서
| 순서 | 할 일 | 메뉴 |
|---|---|---|
| 1 | 직원 명단 올리기 | 데이터 관리 |
| 2 | 평가 관계 확인 | 사람·조직 > 평가 관계 |
| 3 | 문항 확인 | 평가 설계 > 문항 편집 |
| 4 | 평가 시작 | 평가 설계 > 평가 목록 |
| 5 | 진행 확인·반려 | 진행 관리 |
| 6 | 점수·KPI·보정 | 점수·보정 |
| 7 | 결과 확정 | 리포트 |
| 8 | 리포트 보기 | 리포트 |
| 9 | 새 평가 추가 | 평가 설계 > 평가 목록 |
| 10 | 전체 내려받기·전체 삭제 | 데이터 관리 |

**평가를 시작하면 명단·평가 관계·문항·조직도를 고칠 수 없습니다.** (마감일과 퇴사 처리만 가능)
1~3을 꼼꼼히 끝낸 뒤 4로 넘어가세요.

---

## 1. 직원 명단 올리기 (데이터 관리)
1. [데이터 관리] → "직원 명단 올리기"에서 양식(직원명단_양식.csv)을 내려받습니다.
2. 엑셀에서 칸을 채웁니다: 이름, 사번, 부서, 직급, 역할, 평가 제외
   - 역할: 팀원 / 팀장 / 임원
   - 평가 제외: 예 / 아니오 (입사 6개월 미만 등)
   - 사번은 숫자만 씁니다. 사람을 구분하는 기준은 사번입니다.
3. 저장할 때 파일 형식을 **"CSV UTF-8(쉼표로 분리)"** 로 고릅니다.
4. [파일 올리기]로 파일을 고르면 미리보기가 나옵니다. (아직 저장되지 않음)
   | 구분 | 뜻 |
   |---|---|
   | 새 직원 | 처음 보는 사번. 직원과 로그인 계정이 새로 생깁니다 |
   | 바뀜 | 같은 사번인데 부서·직급·역할 등이 달라졌습니다 |
   | 그대로 | 바뀐 것이 없습니다 |
   | 퇴사 후보 | 지금 재직 중인데 파일에 없는 사람. **체크한 사람만** 퇴사 처리됩니다 |
   | 오류 | 줄 번호와 이유가 나옵니다. 하나라도 있으면 적용할 수 없습니다 |
5. 오류가 없으면 [적용] → 확인 창에서 [확인]을 누릅니다.

알아 둘 것
- 평가 중인 회차가 있으면 명단을 올릴 수 없습니다.
- 직원은 지우지 않습니다. 퇴사한 사람은 "퇴사 처리"를 하면 로그인과 조직도에서만 빠지고 평가 기록은 남습니다.
- 평가 중에 퇴사한 사람은 [사람·조직] → [조직도]에서 그 사람을 골라 [퇴사 처리]를 누릅니다. 잘못했으면 [재직으로 되돌리기]를 누릅니다.

## 2. 평가 관계 확인 (사람·조직 > 평가 관계)
누가 누구를 어느 단계에서 평가하는지 확인합니다.
- 한 줄이 평가 대상 한 명입니다: 자기평가 · 팀장 평가자 · 임원 평가자 · 상향 평가자(팀장만) · 임원 상향 평가자(임원만)
- 처음에는 규칙대로 자동으로 채워져 있습니다. 규칙과 다르게 고친 줄은 색으로 표시됩니다.
- 고친 뒤 [저장]을 누릅니다.
- 명단을 다시 올렸다면 [규칙대로 다시 만들기]를 누르세요. 새 직원·부서가 바뀐 사람의 평가 건은 자동으로 바뀌지 않습니다.
  (고쳐 둔 내용은 모두 사라지니 주의하세요)
- 평가 제외·퇴사자는 표에 나오지 않고 맨 아래 "평가 대상 아님"에 접혀 있습니다.

## 3. 문항 확인 (평가 설계 > 문항 편집)
- 평가표 3종(팀원 · 팀장 · 상향)의 문항과 배점을 확인합니다.
- 평가표를 고르고, 문항을 고치거나 [새 문항 추가]로 넣은 뒤 [저장]합니다.
- 배점 합계가 100이어야 평가를 시작할 수 있습니다.
- [미리보기]로 직원에게 보이는 모습을 확인할 수 있습니다. 미리보기에서 쓴 답은 저장되지 않습니다.
- 엑셀(CSV)로 문항을 불러올 수도 있습니다. CSV 파일만 됩니다.

## 4. 평가 시작 (평가 설계 > 평가 목록)
1. 회차 카드에서 평가명과 평가 시작일·마감일을 확인하고 [설정 저장]을 누릅니다.
2. 카드에 "평가를 시작하려면 아래를 먼저 해결해 주세요"가 보이면 그 안내부터 해결합니다.
3. [평가 시작]을 누릅니다.
   - 이제 직원들이 로그인해서 평가를 쓸 수 있습니다.
   - 이때부터 문항·평가 관계·명단·조직도는 잠깁니다.
   - 마감일은 평가 중에도 고칠 수 있습니다. (비울 수는 없습니다)

## 5. 진행 확인·반려 (진행 관리)
### 응답 현황
- 맨 위에서 전체 제출률과 단계별 제출 수를 봅니다.
- [평가자 기준]: 사람마다 해야 할 평가 중 몇 건을 냈는지. 덜 낸 사람이 위로 옵니다.
- [평가 대상 기준]: 사람마다 받을 평가 중 몇 건이 들어왔는지.
- 부서·단계·상태로 거르고 이름으로 찾을 수 있습니다.
- 메일·문자로 독촉하는 기능은 없습니다. 직접 연락해 주세요.

### 반려 (잘못 제출된 평가 되돌리기)
1. 표에서 "제출" 상태인 줄의 [반려]를 누릅니다.
2. 반려 사유를 적습니다. (필수. 평가자가 이 사유를 보게 됩니다)
3. [반려하기]를 누르면 평가자가 모든 문항을 다시 써서 제출해야 합니다.
- 반려 기록은 [진행 관리] → [반려 현황]에 남고, 지우거나 고칠 수 없습니다.
- 다시 제출할 기한(기본 3일)이 남은 날 수로 표시됩니다. (안내용)
- 결과를 확정한 뒤에는 반려할 수 없습니다.

## 6. 점수·KPI·보정 (점수·보정)
점수 순서: **개인 평가 → 부서 KPI·상향 평가와 비율로 섞기 → 보정(필요할 때만)**

### 평가 결과 — 비율 정하기
- 네 묶음의 비율을 정하고 [비율 저장]을 누릅니다. 묶음마다 합계가 100이어야 합니다.
  | 묶음 | 기본값 |
  |---|---|
  | 개인 평가 가중치 (팀원: 자기·팀장·임원 / 팀장: 자기·임원) | 화면에 표시된 값 |
  | 최종 점수 비율 — 팀원 | 개인 80 · KPI 20 |
  | 최종 점수 비율 — 팀장 | 개인 20 · KPI 40 · 상향 40 |
  | 최종 점수 비율 — 임원 | 임원 상향 40 · KPI 60 |
  | 임원 상향 안의 비율 | 팀원 평균 50 · 팀장 평균 50 |
- 저장하면 아래 결과 표가 바로 다시 계산됩니다.
- 내지 않은 평가는 "미제출(0)"로 빨갛게 보이고 0점으로 계산됩니다.

### KPI 반영 — 부서 점수 넣기
- 부서마다 KPI 점수(100점 기준)를 넣고 [저장]을 누릅니다.
- 반영 전·후 평균과 계산 예시가 함께 보입니다.

### 최종 점수 보정
- 보정할 사람을 체크합니다. 여러 명을 한 번에 체크할 수 있습니다.
- 보정 점수와 사유(선택)를 넣고 [넣기] → [저장]을 누릅니다.
- 보정 점수를 비우고 저장하면 보정이 취소됩니다.
- 모든 보정은 아래 "보정 기록"에 누가·언제·몇 점에서 몇 점으로 바꿨는지 남습니다. 지우거나 고칠 수 없습니다.

## 7. 결과 확정 (리포트)
1. [리포트] → [개인 리포트]에서 [결과 확정]을 누릅니다.
2. 확인 창: "확정하면 비율·KPI·보정을 바꿀 수 없습니다" → [결과 확정]
   - 그 순간의 점수가 확정 결과로 저장되고 잠깁니다.
3. 다시 고쳐야 하면 [확정 취소] → 비율·KPI·보정 수정 → 다시 [결과 확정]
   - 확정을 취소해도 저장된 확정 결과는 지워지지 않습니다.

## 8. 리포트 보기 (리포트)
- **개인 리포트** (관리자만): 직원 한 명을 골라 단계별 점수, 최종 점수, 본인이 한 상향 평가, 부서 KPI, 종합 의견을 한 화면에서 봅니다. 면담 자료로 씁니다.
  - 확정 전에는 "지금 점수로 계산한 결과", 확정 후에는 "확정 결과 기준"으로 보입니다.
- **전체 리포트**: 전 직원 결과 요약. [전체 결과 내려받기]로 엑셀(CSV) 파일을 받습니다.
- 직원은 자기 결과를 볼 수 없습니다. 결과는 관리자만 봅니다.
- 상향 평가는 익명입니다. 누가 썼는지는 관리자만 확인할 수 있습니다.

### 건의함
- [건의함]에서 직원이 자기평가 화면에서 보낸 건의를 봅니다.
- 작성자와 보낸 시각은 저장되지 않아 누가 보냈는지 알 수 없습니다. 내용만 가나다순으로 보입니다.

## 9. 새 평가 추가 (평가 설계 > 평가 목록)
- [평가 추가] → 이름(예: 2026 하반기 인사평가)과 복사할 평가를 고르고 [추가]. 문항·반영 비율·부서 KPI가 복사되고, 평가 관계는 규칙대로 새로 만들어집니다.
- 평가 카드 상태: **준비 중**(문항·관계 수정 가능, 여러 개 가능) → **평가 중**(한 번에 하나만) → **완료**(리포트에서 결과 확정)
- 준비 중인 평가는 카드의 [삭제]로 지울 수 있습니다 ("삭제" 입력).
- 대시보드·진행 관리·점수·리포트는 화면 위의 "평가" 상자에서 다른 평가를 고를 수 있습니다. 기본은 지금 평가 중인 평가입니다.
- 평가 중인 평가가 없으면 직원 화면에는 "진행 중인 평가가 없습니다"가 보입니다.
- 새 명단은 데이터 관리에서 올리고, 평가 관계를 확인한 뒤 [평가 시작]을 누르세요.

## 10. 전체 내려받기·전체 삭제 (데이터 관리)

### 전체 내려받기 (백업)
- [전체 내려받기]를 누르면 모든 평가의 자료가 엑셀 파일 1개(인사평가_전체_날짜.xlsx)로 내려받아집니다.
  (평가, 직원, 평가 건, 답, 서술형, 종합 의견, 확정 결과, 보정, 반려, 자기관찰, 건의, 만족도 시트)
- 엑셀에서 열어도 한글이 깨지지 않습니다.

### 전체 삭제 (평가 기록)
- **되돌릴 수 없습니다.** 반드시 전체 내려받기를 먼저 하세요. (내려받기 전에는 버튼이 막혀 있습니다)
- 지우는 것: 평가 기록만 (평가 건·답·확정 결과·보정·반려·건의·만족도)
- 남는 것: 직원·계정·문항·설정
- [전체 삭제] → 칸에 "삭제"라고 입력 → [삭제]

## 자주 묻는 것
| 질문 | 답 |
|---|---|
| 평가 중에 문항이 틀린 걸 알았어요 | 평가 시작 후에는 고칠 수 없습니다. 시작 전에 미리보기로 꼭 확인하세요 |
| 직원이 잘못 제출했어요 | 진행 관리에서 [반려] (결과 확정 전까지만) |
| 평가 중에 퇴사자가 생겼어요 | 사람·조직 > 조직도에서 [퇴사 처리] |
| 확정 후에 점수를 바꿔야 해요 | 리포트에서 [확정 취소] → 수정 → 다시 [결과 확정] |
| 직원이 로그인이 안 돼요 | 이름과 사번이 명단과 같은지, 퇴사 처리되지 않았는지 확인하세요 |
