# 조직도 — 담당: 오재란 (실제 연결: 박수빈)
위치: 사람·조직 > 조직도 (/admin/people/org-chart, 폴더 people-org-chart)
기한: 가짜 데이터로 화면 → 이후 실제 연결

## 0. 목표
회사 전체를 위에서 아래로 직급 순으로 한눈에 보고, 사람을 눌러 부서·직급·역할을 바꾸거나 퇴사 처리한다.

## 1. 디자인 원칙
- 지금 웹페이지 디자인을 그대로 따른다: index.css 색상 변수(파랑·남색·청록), 기존 카드 모양·둥근 모서리·그림자·글꼴
- 참고 그림의 빨강·분홍·주황 같은 색은 쓰지 않는다. 부서 구분은 색 대신 제목과 테두리로
- 연결선은 얇은 회색(--border 계열)
- 글씨는 크게, 누르는 칸은 넉넉하게 (고령 사용자)

## 2. 화면 구성
1. 위쪽: 이름 검색(찾으면 그 사람 카드로 이동·강조), [퇴사자 보기] 켜고 끄기, 평가 중이면 "평가 중에는 조직도를 고칠 수 없습니다" 안내
2. 조직도 (조직도 칸 안에서만 옆으로 밀림)
   - 맨 위: 임원 (직급 높은 순, 같은 줄)
   - 그 아래: 부서 카드가 옆으로 나란히 (부서명 + 인원 수)
   - 각 부서 아래: 직급별 층 (부장 → 차장 → 과장 → 대리 → 주임 → 사원), 같은 직급은 옆으로
   - 사람 카드: 이름, 직급, 역할 배지(팀장은 파랑 배지), 평가 제외는 흐리게 + "평가 제외" 표시
   - 퇴사자는 기본으로 숨김. [퇴사자 보기]를 켜면 흐리게 + "퇴사" 표시
3. 사람 카드를 누르면 편집 칸이 열린다 (데스크톱: 오른쪽, 휴대폰: 아래에서 올라옴)
   - 이름(읽기만), 사번(관리자만 봄)
   - 부서, 직급, 역할 고르기 칸 / 평가 제외 켜고 끄기
   - [저장] [취소]
   - [퇴사 처리] (재직자만) / [재직으로 되돌리기] (퇴사자만): 큰 글씨 확인 상자

## 3. 동작
- 저장하면 조직도가 바로 다시 그려진다 (부서·직급이 바뀌면 카드 위치가 옮겨짐)
- 부서·역할·평가 제외·퇴사가 바뀌면 안내: "평가 관계에서 [규칙대로 다시 만들기]를 눌러 주세요" + 바로 가기
- 회차가 평가 중이면 편집 칸의 입력·버튼이 막힌다. 단, [퇴사 처리]는 평가 중에도 가능 (11/3)
- 직원 삭제는 없다 (퇴사 처리만)

## 4. 데이터
### 가짜 데이터 단계
- src/data/people.ts를 읽어 처음 값으로 쓰고, 고친 내용은 이 페이지 안의 저장 자리(새 파일 src/pages/people-org-chart/org-store.ts)에만 둔다. 새로고침하면 처음으로
- 직급 순서는 people.ts의 직급 목록 순서를 따른다 (실제 연결 때는 positions 표. 팀장·선임연구원 등 추가 가능)
### 실제 연결 단계
| 표 | 읽기 | 쓰기 |
|---|---|---|
| 직원 | 전체 (관리자) | 부서·직급·역할·평가 제외·재직 상태 |
| 부서 | 부서명 | — |
| 직급(positions) | 순서 | — |
| 평가 설정 | 평가 중 여부 | — |
- 서버: 평가 중일 때 직원 표 수정을 막는 잠금 (009_org_lock.sql). 관리자 수정 권한은 002에 이미 있음
  - 11/4 박수빈: 009_org_lock.sql 작성 (실행은 오재란). 평가 중에는 부서·직급·역할·평가 제외·이름·사번 변경을 막고, 재직 상태(퇴사 처리·되돌리기)·계정 연결·새 직원 추가는 허용
  - 009 실행 전에는 화면에서만 막힌다 (저장소는 아직 허용)
- 11/4 실제 연결 (박수빈): src/lib/admin-data.ts의 loadPeople·loadDepartments·loadPositions·loadCurrentCycle로 읽고, saveEmployee·saveEmployeeStatus로 저장
  - 역할 미리보기(가짜 데이터)는 그대로. 가짜 데이터의 "평가 중"은 평가 설계(가짜) 회차 상태를 따른다
