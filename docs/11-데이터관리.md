# 데이터 관리 — 담당: 오재란
위치: /admin/data (폴더 data)

## 0. 목표
차장님이 개발자 없이 1년 운영을 시작할 수 있게 한다.
- 직원 명단을 엑셀로 올려 직원과 로그인 계정을 한 번에 만든다
- 화면은 세 가지: 직원 명단 올리기 · 전체 내려받기 · 전체 삭제
- 평가 추가(이전 평가 복사 또는 빈 평가)·평가 시작·카드 삭제(준비 중일 때만)는 평가 목록에서 한다. 평가 카드별 결과 삭제는 없다

## 1. 화면 구성
### ① 직원 명단 올리기
1. [양식 내려받기]: 칸이 정해진 빈 CSV (이름, 사번, 부서, 본부, 직급, 역할, 평가 제외). 본부는 임원만 저장 (팀원·팀장은 부서에서 정해짐)
2. [파일 올리기]: 엑셀에서 "CSV UTF-8"로 저장한 파일을 고른다
3. 미리보기 (아직 저장 안 됨)
   | 구분 | 뜻 |
   |---|---|
   | 새 직원 | 사번이 처음 → 직원 + 로그인 계정 생성 |
   | 바뀜 | 같은 사번, 이름·부서·본부·직급·역할·평가 제외·재직 상태가 다름 → 고침 |
   | 그대로 | 바뀐 것 없음 |
   | 퇴사 후보 | 지금 재직인데 파일에 없음 → **체크한 사람만** 퇴사 처리 |
   | 오류 | 이름 빈칸, 사번이 숫자가 아님, 사번 중복, 없는 부서·본부(이름이 정확히 같아야 함), 팀원·팀장의 본부가 부서의 본부와 다름, 잘못된 직급·역할, 평가 제외가 예·아니오가 아님 → 줄 번호와 이유 |
4. 오류가 하나라도 있으면 [적용]이 막힌다
5. [적용] → 큰 글씨 확인 상자 → 서버가 한 번에 처리 → 결과(새 n, 바뀜 n, 퇴사 n, 계정 생성 n, 계정 생성 실패 n)
- 회차가 "평가 중"이면 올리기 전체를 막는다 (평가 도중 사람이 바뀌면 평가 건이 꼬임). 단, 퇴사 처리는 평가 중에도 가능 (조직도에서)

### ④ 전체 삭제 (11/3)
- 지우는 것: 모든 평가의 평가 건·답·종합 의견·확정 결과·보정·반려·자기관찰·만족도·건의. 범위 선택 없음
- 남기는 것: 평가 카드(준비 중으로)·문항·반영 비율·부서·본부·부서 KPI·직급 목록·직원 명단·직원 계정·관리자 계정
- 관리자만. [전체 내려받기]를 한 뒤에만 버튼이 열린다. 확인 창에 "삭제"를 입력해야 실행. 서버 함수로 한 번에

### ② 전체 내려받기 (백업)
- 모든 평가를 엑셀 파일 1개(인사평가_전체_YYYYMMDD.xlsx)로 내려받는다. 시트 12개: 평가, 직원, 평가 건, 답, 서술형, 종합 의견, 확정 결과, 보정, 반려, 자기관찰, 건의, 만족도
- 보관·열람용: 칸 이름·값은 한글, 내부 번호 대신 평가 이름·대상(이름·부서·직급)·평가자 이름, 답은 구분·평가 내용·문항·A~E·점수, 첫 줄 고정·칸 너비 자동
- 엑셀 도구는 SheetJS 공식판 xlsx 0.20.3 (cdn.sheetjs.com, 버전 고정). 버튼을 누를 때만 불러온다
- 건의·만족도는 작성자가 없으니 그대로 내보내도 된다

## 2. 서버
| 무엇 | 왜 |
|---|---|
| Edge Function import-employees (supabase/functions/import-employees/index.ts) | 로그인 계정을 만들려면 관리용 열쇠가 필요한데, 화면(브라우저)에 둘 수 없어서 Supabase 안의 작은 서버 프로그램이 처리 |
| 함수 안에서 부른 사람이 관리자인지 먼저 확인 | 직원이 부르면 거부 |
| 관리용 열쇠는 Supabase가 함수 안에 자동으로 넣어 줌 | 열쇠를 코드·파일에 적지 않는다 |
| 미리보기는 화면이 계산, 적용은 함수가 다시 검사 | 화면을 믿지 않는다 |
| 계정 아이디·비밀번호 규칙은 scripts/create-accounts.mjs와 같게 | 사번@daeyang-hr.local, 6자리 미만은 앞에 0 |
| 퇴사 처리 = 재직 상태만 "퇴사" (삭제 없음) | 기록 보존 |
- 배포: Supabase 웹의 Edge Functions 화면에 저장소 파일 전체를 붙여 넣는다 (Verify JWT 켬). 고치면 저장소를 먼저 고치고 다시 붙여 넣는다

## 3. 시험 (주의: 계정은 되돌릴 수 없음)
- 명단 검사·미리보기는 화면에서 마음껏 시험
- 실제 [적용] 시험은 시험용 1명(사번 999999)만 넣고, 끝나면 정리 SQL로 그 사람과 계정을 지운다
- 시험 후 직원 30명, 계정 31개(관리자 포함), 90 시연 초기화 확인 쿼리가 그대로인지 확인

## 4. 볼 수 있는 사람
- 관리자만. 사번이 보이는 유일한 화면 (관리자는 원래 볼 수 있음)

## 5. 하지 않을 것
- .xlsx 직접 읽기 (명단 올리기는 CSV만)
- 직원 삭제
- 비밀번호 변경

## 6. 완료 체크리스트
