# 데이터 관리 — 담당: 오재란
위치: /admin/data (폴더 data)

## 0. 목표
차장님이 개발자 없이 1년 운영을 시작할 수 있게 한다.
- 직원 명단을 엑셀로 올려 직원과 로그인 계정을 한 번에 만든다
- 새 해 평가 전에 지난 자료를 내려받고 새 회차를 만든다

## 1. 화면 구성
### ① 직원 명단 올리기
1. [양식 내려받기]: 칸이 정해진 빈 CSV (이름, 사번, 부서, 직급, 역할, 직군, 평가 제외)
2. [파일 올리기]: 엑셀에서 "CSV UTF-8"로 저장한 파일을 고른다
3. 미리보기 (아직 저장 안 됨)
   | 구분 | 뜻 |
   |---|---|
   | 새 직원 | 사번이 처음 → 직원 + 로그인 계정 생성 |
   | 바뀜 | 같은 사번, 이름·부서·직급·역할·직군·평가 제외가 다름 → 고침 |
   | 그대로 | 바뀐 것 없음 |
   | 퇴사 후보 | 지금 재직인데 파일에 없음 → **체크한 사람만** 퇴사 처리 |
   | 오류 | 사번이 숫자가 아님, 사번 중복, 없는 부서, 잘못된 직급·역할·직군 → 줄 번호와 이유 |
4. 오류가 하나라도 있으면 [적용]이 막힌다
5. [적용] → 큰 글씨 확인 상자 → 서버가 한 번에 처리 → 결과(새 n, 바뀜 n, 퇴사 n, 계정 생성 실패 n)
- 회차가 "평가 중"이면 올리기 전체를 막는다 (평가 도중 사람이 바뀌면 평가 건이 꼬임). 단, 퇴사 처리는 평가 중에도 가능 (조직도에서)

### ④ 전체 삭제 (11/3)
- 지우는 것: 평가 기록만 (평가 건·답·확정 결과·보정·반려·건의·만족도). 직원·계정·문항·설정은 남긴다. 범위 선택 없음
- 관리자만. [전체 내려받기]를 한 뒤에만 버튼이 열린다. 확인 창에 "삭제"를 입력해야 실행. 서버 함수로 한 번에

### ② 전체 내려받기 (백업)
- 회차를 고르고 CSV 묶음을 내려받는다: 직원, 평가 건, 답, 확정 결과, 보정 기록, 반려 기록
- 엑셀에서 한글이 안 깨지게 파일 앞에 BOM
- 건의·만족도는 작성자가 없으니 그대로 내보내도 된다

### ③ 새 해 평가 시작 순서
화면에 단계로 보여 준다. 각 단계 완료 체크를 해야 다음 단계 버튼이 열린다.
1. 지난 회차 전체 내려받기 (②)
2. 새 회차 만들기: 이름 입력 → new_cycle (직전 설정·문항 복사, 평가 건 "평가 전"으로 생성)
3. 새 명단 올리기 (①) → 평가 관계 확인 → 평가 목록에서 [평가 시작]
- 지난 회차 자료는 지우지 않는다 (초기화 = 새 회차)

## 2. 서버
| 무엇 | 왜 |
|---|---|
| Edge Function import-employees (supabase/functions/import-employees/index.ts) | 로그인 계정을 만들려면 관리용 열쇠가 필요한데, 화면(브라우저)에 둘 수 없어서 Supabase 안의 작은 서버 프로그램이 처리 |
| 함수 안에서 부른 사람이 관리자인지 먼저 확인 | 직원이 부르면 거부 |
| 관리용 열쇠는 Supabase가 함수 안에 자동으로 넣어 줌 | 열쇠를 코드·파일에 적지 않는다 |
| 미리보기는 화면이 계산, 적용은 함수가 다시 검사 | 화면을 믿지 않는다 |
| 계정 아이디·비밀번호 규칙은 scripts/create-accounts.mjs와 같게 | 사번@daeyang-hr.local, 6자리 미만은 앞에 0 |
| 퇴사 처리 = 재직 상태만 "퇴사" (삭제 없음) | 기록 보존 |
- 배포: Supabase 웹의 Edge Functions 화면에 코드를 붙여 넣거나 CLI로. 방법은 계획 때 정한다

## 3. 시험 (주의: 계정은 되돌릴 수 없음)
- 명단 검사·미리보기는 화면에서 마음껏 시험
- 실제 [적용] 시험은 시험용 1명(사번 999999)만 넣고, 끝나면 정리 SQL로 그 사람과 계정을 지운다
- 시험 후 직원 28명, 계정 29개, 90 시연 초기화 확인 쿼리가 그대로인지 확인
