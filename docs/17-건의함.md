# 건의함 — 담당: 박수빈
(11/2 작성. 원래 강영주 ③ "건의함·만족도 보기"였으나 이야기해서 박수빈이 맡음. 만족도 보기는 뒤에 직원 의견 > 만족도(src/pages/satisfaction)로 따로 만들었다)

## 0. 목표
관리자가 직원이 보낸 건의를 본다. 건의는 **작성자를 알 수 없게** 받았으므로 관리자 화면도 **내용만** 보여 준다.
작성자·작성 시각·순서로 누가 보냈는지 짐작할 수 있는 정보는 보여 주지 않는다.

## 1. 페이지·폴더
| 주소 | 폴더 | 이번 범위 |
|---|---|---|
| /admin/suggestions | suggestions | ✅ 건의함 (관리자만) |
- 사이드바: 리포트 아래, 데이터 관리 위의 "직원 의견" 메뉴 → 하위 메뉴 건의함 · 만족도 (관리자 화면은 PC 기준)
- 직원(팀원·팀장·임원) 사이드바에는 없다. 주소로 들어오면 자기 첫 페이지로 간다 (공통 규칙)

## 2. 화면 구성
1. 제목 "건의함" + 설명 "직원이 자기평가 화면에서 보낸 건의입니다."
2. 요약 칸: 회차 이름(예: 정기 인사평가 (1회차)) · "받은 건의 n건" · 안내 "작성자와 보낸 시각은 저장되지 않아 누가 보냈는지 알 수 없습니다."
3. 건의 카드 목록: 카드에는 **내용만** (번호·작성자·시각·"새 건의" 표시 없음). 여러 줄이면 줄바꿈 그대로
4. 순서: 받은 순서가 아니라 **내용의 가나다순**
5. 건의가 없으면 "아직 받은 건의가 없습니다."
- 화면 안에 회차 선택 칸은 없다. 상단바의 평가 선택 상자에서 고른 평가의 건의를 보여 준다 (기본: 평가 중인 평가, 없으면 가장 최근 평가)

## 4. 볼 수 있는 사람
- 관리자만. 관리자도 작성자는 알 수 없다 (서버 표에 작성자·날짜·시각 칸이 없음)

## 5. 하지 않을 것
- 만족도 보기 (직원 의견 > 만족도 화면에서 본다: 평균 점수, 점수별(1~5) 인원, 응답률 = 응답 수 / 자기평가 건 수, 의견 가나다순, 익명)
- 작성자·작성 시각·받은 순서 보여 주기, 번호 붙이기
- 건의 고치기·지우기, 답장
- 검색, 내려받기 (건의는 데이터 관리 [전체 내려받기] 엑셀의 "건의" 시트에 들어 있다)
- 직원의 건의·만족도 보내기 화면 변경 (docs/12 그대로)
