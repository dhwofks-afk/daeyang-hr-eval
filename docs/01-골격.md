# 1단계: 메인 골격

## 0. 목표와 완료 기준
- 목표: Figma 시안을 3인 팀이 페이지별로 나눠 작업할 수 있는 골격으로 바꾼다.
- 완료 기준
  - 내 컴퓨터에서 pnpm dev로 실행된다.
  - 모든 페이지가 고유 주소로 열린다. (내용은 "준비 중"이어도 됨)
  - 페이지마다 파일이 분리되어 있고, 페이지 추가가 아래 3단계로 끝난다.
    1. 페이지 폴더 복사  2. 주소 목록에 한 줄 추가  3. 가짜 데이터 추가
  - pnpm build가 오류 없이 끝난다.
  - 화면 모양은 시안과 같고, 5번 변경 사항만 달라진다.

## 1. 작업 순서
각 단계를 마치면 멈추고 결과를 보고한 뒤 승인을 받고 다음 단계로 간다.
1. Figma 전용 장치 정리 → pnpm dev 실행 확인
2. App.tsx를 페이지별 파일로 분리 (화면 변화 없어야 함)
3. 페이지 주소 부여 (주소용 라이브러리 후보 제안 → 승인 후 설치)
4. 공통 틀 분리 (사이드바·상단바·모바일 메뉴)
5. index.css를 공통 스타일과 페이지별 스타일로 분리
6. 가짜 데이터를 한 폴더로 모으기
7. 시안 대비 변경 사항 반영
8. pnpm build 확인 후 최종 보고

## 3. 공통 틀

### 사이드바
- 역할에 따라 메뉴가 다르다: 관리자 메뉴 8개 / 참여자 메뉴 2개
- 하위 페이지가 있는 메뉴(사람·조직, 평가 설계, 점수·보정)는 눌렀을 때 하위 메뉴가 펼쳐진다.
- 현재 페이지가 사이드바에 강조 표시된다.
- 맨 아래 언어 선택: 메뉴는 보이되 "준비 중" 표시

### 상단바
- 사용자 이름·역할 표시, 로그아웃만 둔다.

### 모바일
- 좁은 화면에서는 사이드바가 숨고 메뉴 버튼으로 연다.

### 로그인 후 첫 페이지
- 관리자 → /admin (대시보드)
- 팀원·팀장·임원 → /my/evaluations
- 로그인 화면의 "역할 미리보기"는 유지한다 (프로토타입 전용 표시)

### 빈 페이지 틀
- 아직 만들지 않은 페이지는 같은 모양으로 보여 준다:
  페이지 제목 / 한 줄 설명 / "준비 중" 표시
- 시안의 기능 설명 카드는 담당자 참고용으로 남긴다. (문구는 5번 표대로 수정)

### 대시보드
- 각 카드를 누르면 해당 상세 페이지로 이동한다.

## 4. 가짜 데이터
- 화면에 보이는 숫자·목록을 src/data/ 한 곳에 모은다. 페이지 파일에는 숫자를 직접 쓰지 않는다.
- 부서·인원은 실제 구성에 맞춘다: 경영기획부 3명 / 영업부 6명 / 생산 18명 (총 27명)
- 사람 이름은 가상 이름을 쓴다.
- 대시보드 숫자도 27명 기준으로 맞춘다. (예: 응답 완료 19명 / 미응답 8명 / 응답률 70%)
- 이 데이터는 데이터 설계 이후 실제 구조로 교체된다. 계산 기능을 만들지 않는다.
  (대시보드는 이후 실제 응답 기반 그래프로 교체 예정)

## 5. 시안 대비 변경 사항

### 메뉴·구조
- 사람·조직 하위: 조직도 / 평가 관계 (직원 목록·계정 관리 삭제)
- 평가 설계 하위: 평가 목록 / 문항 편집 (자기평가·팀원평가·팀장평가 하위 페이지)
- 점수·보정 하위: 평가 결과 → KPI 반영 → 최종 점수 보정
- 데이터 관리: 설명에 "직원 명단 업로드" 추가
- 상단바: 메뉴 검색·고객지원·알림 삭제

### 문구
- 로그인 화면: "개인 링크를 받으셨나요?" 안내 삭제
- 점수·보정 > 부서 KPI: 상태 "자료 대기" 삭제
- 사람·조직 설명 카드: 계정 관리(링크 발급 등) 내용 삭제
- 내 설정: 비밀번호 변경 내용 삭제 (언어 선택 "준비 중"만 남김)
- 언어 선택: "준비 중" 표시

### 설명 카드 문구
| 페이지 > 칸 | 수정 후 |
|---|---|
| 평가 작성 > 평가 대상 | 임원은 배정된 팀원·팀장을 한 명씩 평가 |
| 평가 작성 > 입력·제출 | (기존 유지) + 평가 의견 한 줄 이상 필수 / 전 단계 완료 여부 표시 |
| 내 결과 | PDF·Excel 내보내기 + 관리자가 "결과 공개"한 뒤 열람, 공개 범위 안의 항목만 |
| 사람·조직 > 조직도 | 부서 관리, 직급 관리 + 명단은 데이터 관리에서 업로드 / 삭제 대신 퇴사 처리 / 평가 중 수정 잠금 |
| 사람·조직 > 평가 관계 | 부서별 평가자–대상 설정·수정 / 시각화 방식은 페이지 단계에서 결정 |
| 평가 설계 > 평가 목록 | 카드형, 평가 전·평가 중·평가 완료 / 평가 전 = "평가 시작"(시작일·마감일), 평가 중 = "마감일 수정" |
| 평가 설계 > 가중치 | 팀원용(3단계)·팀장용(2단계) 따로 설정, 기본값 회사 확인 중 |
| 평가 설계 > 문항 편집 | 웹 편집, 엑셀 업로드, 순서 수정 + 카드 3개(자기평가·팀원평가·팀장평가) / 우측 상단 미리보기 |
| 평가 설계 > 평가 시작 | 문항·대상자·평가자·관계·조직도 잠금 / 마감일은 수정 가능 |
| 진행 관리 > 제출 반려 | 제출 상태를 되돌려 다시 작성 + 필터·검색 |
| 진행 관리 > 안내·독촉 | 카카오톡 챗봇 검토, 불가 시 생략 (차후 연결 유지) |
| 점수·보정 > 최종 점수 보정 | 숫자 직접 입력, 생략 가능 / 모든 보정 로그 기록 / 한 페이지에서 전·후 비교 |
| 점수·보정 > KPI 반영 | 부서 KPI 점수(100점 기준) 입력, 원점수 vs 반영 점수 비교 / 반영 산식 회사 확인 중 |
| 리포트 > 요약 리포트 | 항목별·전체 선택 체크리스트, 회사 전체 대상 |
| 리포트 > 개인 리포트 | 직원 공개 / 공개 범위 체크리스트(전 직원 일괄) / "결과 공개" 버튼 / 공개 후 수정 제한 방식은 페이지 단계에서 결정 |
| 리포트 > 면담 리포트 | 직원별, 인사팀장만 열람 |
| 면담 지원 AX | 구현 범위 추가 논의 예정 (보류) |
| 데이터 관리 | 내보내기, 초기화 + 직원 명단 엑셀 업로드 / 연초 순서: 내려받기 → 초기화 → 새 명단 업로드 |

### 숫자
- 부서: 경영기획부 3 / 영업부 6 / 생산 18 (총 27명)
- 대시보드 숫자 27명 기준으로 수정

### 색상
- 청록 계열 → 로고 색상: 파랑 #01529D / 남색 #1C1F4D / 청록 #23B6C8(보조)

### 사이트 설정 (.figma/make/site.json)
- 제목: "대양롤랜트 인사평가"
- 설명에서 동료 평가 문구 삭제
- 아이콘: 회사 로고로 교체 (원형 로고 파일 사용)

## 6. 하지 않을 것
- 데이터 저장소·서버 연결
- 실제 로그인 확인 (역할 미리보기로 대신함)
- 계산 기능 (응답률, 가중 합산, KPI 반영, 등급 산정)
- 페이지 내부 기능 (엑셀 업로드, 문항 편집, 반려, 보정 입력 등)
- 새 화면의 내용 (상대평가 등급 설정 등)
- 외부 연결 (분석 도구, AI 호출, 카카오톡)
- 번역 기능
- 배포
- 시안에 없는 디자인 추가·변경 (5번 변경 사항 제외)
- 새 라이브러리 설치. 단, 페이지 주소용 라이브러리 1개는 예외:
  1단계 계획 보고 때 후보를 제안하고 승인을 받은 뒤 설치한다.

## 7. 완료 체크리스트 (사람이 직접 확인)

### 실행
- [ ] pnpm dev 후 브라우저에서 열린다
- [ ] pnpm build가 오류 없이 끝난다

### 로그인·권한
- [ ] 역할 미리보기로 팀원·팀장·임원·관리자 각각 들어가면 정해진 첫 페이지가 나온다
- [ ] 팀원으로 들어간 뒤 주소창에 /admin을 직접 치면 팀원 첫 페이지로 돌아간다

### 주소
- [ ] 2번 표의 주소를 하나씩 직접 입력하면 모두 열린다
- [ ] 아무 페이지에서 새로고침해도 같은 페이지가 유지된다
- [ ] 뒤로 가기가 정상 동작한다

### 공통 틀
- [ ] 현재 페이지가 사이드바에 강조된다
- [ ] 사람·조직, 평가 설계, 점수·보정을 누르면 하위 메뉴가 펼쳐진다
- [ ] 휴대폰 너비에서 사이드바가 숨고 메뉴 버튼으로 열린다
- [ ] 상단바에 이름·역할·로그아웃만 있다

### 변경 사항
- [ ] 색상이 로고 기준(파랑·남색·청록)으로 바뀌었다
- [ ] 부서가 3개, 총 27명으로 보인다
- [ ] 브라우저 탭에 "대양롤랜트 인사평가"와 회사 로고가 보인다
- [ ] 설명 카드 문구가 5번 표대로 바뀌었다

### 합치기 준비
- [ ] App.tsx가 짧아지고, src/pages/ 아래 페이지별 폴더가 있다
- [ ] 연습용 빈 페이지를 하나 만들어 "3단계 추가"를 해 보면 실제로 그것만으로 붙는다
      (확인 후 연습 페이지는 지운다)
