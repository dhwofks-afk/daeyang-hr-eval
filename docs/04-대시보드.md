# 대시보드 — 담당: 박수빈
기한: 11/1 화면(가짜 데이터) → 11/4 실제 데이터 연결

## 0. 목표
발표 4번 장면: 관리자가 로그인하면 "누가 얼마나 제출했는지"가 실제 숫자로 보인다.
점수가 나오면 부서별 평균도 함께 보인다.

## 1. 페이지·폴더
| 주소 | 폴더 | 이번 범위 |
|---|---|---|
| /admin | admin-dashboard | ✅ 이미 있는 페이지 → 다른 작업 전에 CSS 클래스 이름에 페이지 이름부터 붙인다 (00-팀원-안내 5번 경우 3) |

## 2. 화면 구성 (위에서 아래로)
1. 상단 요약 띠: 회차 이름 · 상태 · 마감까지 D-n (미정이면 "미정", 당일 "D-day", 지나면 "마감 지남")
   - 큰 배너("함께 성장하는 더 나은 내일")는 없애고 이 요약 띠로 줄였다
2. 평가 진행 현황
   - 전체 제출률 원형 그래프 (평가 건 수로 계산)
   - 단계별 제출: 자기평가 · 팀장평가 · 임원평가 · 상향평가 · 임원상향평가 n/N + 합계 n/N건
   - 미제출 인원 수 → 누르면 미제출자 이름 목록 펼침
3. 부서별 진행률: 부서마다 "n/N건 · %" + 막대 (평가 대상의 부서로 센다)
4. 부서별 평균 점수: 모든 평가를 제출받은 직원의 최종 점수 평균이며 "제출 완료 n/N명 기준"을 함께 표시 (scoring.ts의 최종 점수 사용. 제출 완료자가 없으면 "평가 진행 중")
5. 카드 "상세보기" → 진행 관리(응답 현황) / 점수·보정(평가 결과) 페이지로 이동
- 일정 카드는 뺀다 (날짜가 모두 미정)

## 3. 동작
- 대시보드는 숫자를 저장하지 않는다. 페이지를 열 때마다 평가 건의 "상태"를 세서 계산한다
- 점수는 scoring.ts를 불러다 쓴다 (직접 계산하지 않음)
- 최신 반영: 페이지를 열거나 새로고침할 때 최신 숫자로 바뀐다
  - (11/4 이후 시간이 남으면) 새로고침 없이 저절로 바뀌는 실시간 반영을 얹는다. 화면 구조는 그대로 둔다

### 11/1까지 (가짜 데이터)
- 기존 src/data/dashboard.ts를 고쳐 쓴다.
  **예외 허락: dashboard.ts는 대시보드 전용 파일이라 박수빈이 고쳐도 된다.** (CLAUDE.md보다 이 문서가 우선)
  PR 내용에 "공통 파일 변경: dashboard.ts"라고 적는다.
- 숫자를 직접 적지 말고, 평가 건 모양의 가짜 목록(누가·어느 단계·제출 여부)을 두고 그걸 세서 숫자를 만든다.
  그래야 11/4에 가짜 목록을 실제 표로 바꾸기만 하면 된다.
- 점수는 오재란이 먼저 만드는 src/lib/scoring.ts와 src/data/scores.ts를 읽기만 해서 쓴다
- 11/4 실제 연결 후 dashboard.ts는 역할 미리보기에서만 쓴다

### 11/4 실제 연결
- 평가 건: 진행 관리와 같은 저장 자리(src/data/progress-store.ts)의 서버 칸을 읽는다 (admin-data의 loadProgress). 진행 관리에서 반려하면 대시보드 숫자도 바뀐다
- 회차 이름·상태·마감일도 같은 서버 칸에서 읽는다. 상단바 평가 선택 상자에서 고른 평가 기준 (016, 평가를 바꾸면 다시 읽는다)
- 점수: admin-data의 loadScoreData → scoreResultsOf (scoring.ts). 읽는 데 7~8초 걸려서 제출 현황을 먼저 보여 주고, 부서별 평균 점수는 "점수를 불러오는 중입니다…" 뒤에 채운다
- 단계별 제출은 자기평가·팀장평가·임원평가·상향평가·임원상향평가 다섯 줄 + 합계 줄. 전체 제출률이 모든 평가 건을 세므로 다섯 줄 합계가 원형 그래프와 같다
- 역할 미리보기(로그인 없음)는 가짜 데이터(dashboard.ts·scores.ts) 그대로

- 숫자를 페이지 파일에 직접 적기

## 7. 완료 체크리스트
- [ ] CSS 클래스 이름에 페이지 이름이 붙었고, 이름 바꾸기 전후 화면이 같다
- [ ] 가짜 평가 건 목록에서 하나를 "제출"로 바꾸면 제출률·단계별 숫자·부서별 진행률이 함께 바뀐다
- [ ] 제출률 원형 그래프가 숫자와 정확히 맞는다 (69% 고정 없음)
- [ ] 미제출 인원 수를 누르면 이름 목록이 펼쳐진다
- [ ] 부서별 평균 점수가 제출 완료자 기준이고 n/N명 표시가 맞다
- [ ] 상단바에서 평가를 바꾸면 그 평가의 숫자로 바뀐다
- [ ] 마감일이 없으면 "미정", 지나면 "마감 지남"으로 보인다
- [ ] 큰 배너는 요약 띠로 줄었고 일정 카드는 없다
- [ ] "상세보기"가 맞는 페이지로 이동한다
- [ ] pnpm build, pnpm exec tsc --noEmit 통과
